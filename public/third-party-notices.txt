ASSETS
------

None. Every visual and every sound is generated by code in this repository: the
cards are DOM and inline SVG drawn from the path table in src/render.ts, the palette
is solved in src/palette.ts, the icons come from scripts/gen-icons.mjs, and the audio
is synthesised with the Web Audio API. No third-party fonts, images, sprites or sound
files, and nothing is fetched from a CDN.

GAME RULES
----------

Tacit is an original implementation of a co-operative hidden-task trick-taking game.
Game mechanics are not subject to copyright; the name, deck, suits, mission ladder,
artwork and text here are original to this repository and reference no other product.

NETWORK
-------

Cloudflare Web Analytics (static.cloudflareinsights.com) — anonymous, cookie-less
page-view counts. The hosted feedback widget (feedback.benrichardson.dev).
Multiplayer only: public WebRTC signalling relays, and short-lived TURN credentials
from rt.benrichardson.dev for peers that cannot form a direct connection. No game
state passes through any of them.
